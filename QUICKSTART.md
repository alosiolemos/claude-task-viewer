# Começar rapidamente

1. Baixe [painel-execucao-0.8.3.vsix](https://github.com/alosiolemos/claude-task-viewer/releases/tag/v0.8.3).
2. No VS Code: Extensões → … → Instalar a partir do VSIX.
3. Abra a pasta usada no Claude e procure **Abrir Visualização de Execução do Claude** em Ctrl+Shift+P.
4. Confira a sessão, crie uma tarefa e acompanhe as ações.
