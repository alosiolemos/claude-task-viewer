# Exemplo reduzido de exportação

[Ver o exemplo JSON](exportacao-resumida.json)

O arquivo demonstra, de forma resumida, o que pode ser consultado num relatório de tarefa: origem, objetivo, etapas e cuidados de privacidade. Foi inspirado em uma exportação real compartilhada pelo autor, mas os conteúdos foram reescritos e os dados são genéricos. Não é uma cópia da conversa, uma exportação completa ou um arquivo para importar no painel.

Para gerar seu próprio relatório, clique em **Exportar tarefa**, revise as categorias e termos a ocultar e escolha HTML ou JSON. A exportação usa somente a tarefa selecionada e não chama o Gemini. Revise os dados antes de compartilhar.
