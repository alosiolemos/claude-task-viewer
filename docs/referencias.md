# Referências e projetos relacionados

[← Voltar à apresentação](../README.md)

A pesquisa de apresentação para esta publicação encontrou ferramentas relacionadas. Por isso, não apresentamos o projeto como o primeiro ou único visualizador de sessões.

| Projeto | O que apresenta | Aprendizado para a documentação |
| --- | --- | --- |
| [Trace](https://github.com/gpolaert/trace) | Visualizador local de transcrições do Claude Code e Codex | Explicar primeiro o problema e o que o usuário consegue observar |
| [AI Operations Room](https://github.com/mewsdev/AiOperationsRoom) | Sala local para acompanhar sessões e subagentes do Claude Code | Mostrar arquitetura, comportamento e limitações com clareza |
| [Simplify Claude](https://github.com/marium-noor/simplify-claude) | Extensão que apresenta resumos de sessões em linguagem simples | Priorizar a compreensão de quem não domina os termos técnicos |

Nosso foco é reunir **fluxo por tarefa, detalhes da ação, comentário original e explicação opcional** dentro do VS Code. Os projetos relacionados têm propostas e requisitos próprios; a comparação não é um benchmark nem uma declaração de superioridade. Nenhum deles precisa ser instalado para usar esta extensão.

A organização desta documentação também segue o padrão do projeto do autor [Visão financeira para CS — Sankhya → HubSpot](https://github.com/alosiolemos/n8n-sankhya-hubspot-financial-sync): problema, fluxo, screenshots, escopo e instruções para explorar.

O formato local de transcrição é interno do Claude Code e sujeito a mudanças, conforme a [documentação oficial de sessões](https://code.claude.com/docs/en/sessions#where-transcripts-are-stored). A visualização precisa continuar detectando incompatibilidades, em vez de interpretar dados desconhecidos silenciosamente.

Referências consultadas em 09/11/2026. Inspiração em workflows visuais como os do n8n não indica vínculo oficial com o produto. Não foram incorporados código ou assets desses projetos nesta preparação.
